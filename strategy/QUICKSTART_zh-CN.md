# ⚡ NEXUS 快速上手指南

> **只需 5 分钟，即可从零开始构建编排化的多智能体流水线。**

---

## 什么是 NEXUS？

**NEXUS** (Network of EXperts, Unified in Strategy，即：策略统一的专家网络) 将 The Agency 的 AI 专家们转化为一套协同工作的流水线。不同于一次激活一个智能体并寄希望于他们能自发合作，NEXUS 明确定义了谁在什么时候做什么，以及如何在每一步验证质量。

## 选择你的模式

| 我的目标是... | 使用模式 | 投入智能体数量 | 预计耗时 |
|-------------|-----|--------|------|
| 从头开始构建完整产品 | **NEXUS-Full** | 全部 | 12-24 周 |
| 构建一个功能或 MVP | **NEXUS-Sprint** | 15-25 个 | 2-6 周 |
| 执行特定任务（Bug 修复、活动、审计） | **NEXUS-Micro** | 5-10 个 | 1-5 天 |

## 🚀 NEXUS-Full：启动完整项目

**复制此提示词以激活完整流水线：**

```
以 NEXUS-Full 模式激活智能体编排师 (Agents Orchestrator)。

项目名称：[你的项目名称]
需求规范：[描述你的项目或提供规范链接]

执行完整的 NEXUS 流水线：
- 阶段 0：发现 (趋势研究员, 用户反馈分析师, 用户体验研究员, 数据分析报告员, 法律合规检查员, 工具评估专家)
- 阶段 1：策略 (工作室制作人, 高级项目经理, Sprint 优先级规划师, UX 架构师, 品牌守护者, 后端架构师, 财务追踪专员)
- 阶段 2：基础 (DevOps 自动化工程师, 前端开发工程师, 后端架构师, UX 架构师, 基础设施维护工程师)
- 阶段 3：构建 (开发↔QA 循环 —— 所有工程智能体 + 测试证据采集员)
- 阶段 4：加固 (生产就绪验证员, 性能基准测试专家, API 测试工程师, 法律合规检查员)
- 阶段 5：发布 (增长黑客, 内容创作者, 所有营销智能体, DevOps 自动化工程师)
- 阶段 6：运营 (数据分析报告员, 基础设施维护工程师, 客户支持专员, 持续进行)

每个阶段之间必须设立质量门禁。所有评估均需提供证据。
每项任务在升级前最多重试 3 次。
```

## 🎯 NEXUS-Micro：执行特定任务

**选择你的场景并复制提示词：**

### 修复 Bug
```
激活后端架构师以调查并修复 [BUG 描述]。
修复后，激活 API 测试工程师验证修复情况。
随后激活测试证据采集员确认无视觉回归。
```

### 运行营销活动
```
激活社交媒体策略师作为 [活动描述] 的活动负责人。
团队成员：内容创作者, Twitter 运营专家, Instagram 运营专家, Reddit 社区运营。
品牌守护者在发布前审查所有内容。
数据分析报告员每日追踪表现。
增长黑客每周优化渠道。
```

### 执行合规审计
```
激活法律合规检查员进行全面合规审计。
范围：[GDPR / CCPA / HIPAA / 全部]
审计后，激活高管摘要生成师创建利益相关者报告。
```

### 调查性能问题
```
激活性能基准测试专家诊断性能问题。
范围：[API 响应时间 / 页面加载 / 数据库查询 / 全部]
诊断后，激活基础设施维护工程师进行优化。
DevOps 自动化工程师部署任何基础设施变更。
```

### 市场研究
```
激活趋势研究员以获取关于 [领域] 的市场情报。
交付物：竞争态势、市场规模、趋势预测。
研究后，激活高管摘要生成师编写高管简报。
```

### UX 改进
```
激活用户体验研究员以识别 [功能/产品] 中的易用性问题。
研究后，激活 UX 架构师设计改进方案。
前端开发工程师实现变更。
测试证据采集员验证改进效果。
```

## 🔑 30 秒掌握核心概念

1. **质量门禁 (Quality Gates)** — 未经基于证据的批准，不得进入下一阶段。
2. **开发↔QA 循环 (Dev↔QA Loop)** — 每项任务先构建后测试；通过 (PASS) 则继续，失败 (FAIL) 则重试（最多 3 次）。
3. **交付 (Handoffs)** — 智能体之间结构化的上下文转移（严禁在无背景的情况下开始）。
4. **生产就绪验证员 (Reality Checker)** — 最终质量权威；默认状态为“需改进 (NEEDS WORK)”。
5. **智能体编排师 (Agents Orchestrator)** — 管理整个流程的流水线控制器。
6. **证据胜于雄辩 (Evidence Over Claims)** — 截图、测试结果和数据才是硬道理，而非口头保证。
