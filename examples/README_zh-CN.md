# 案例集 (Examples)

本目录包含了一系列示例产出，展示了 The Agency 的各个智能体如何被编排在一起，共同解决现实世界中的任务。

## 为什么存在这个目录？

`agency-agents` 仓库定义了数十个分布在工程、设计、营销、产品、支持、空间计算和项目管理领域的专业智能体。但仅仅看智能体的定义，无法展现出当你**同时部署所有角色**去执行单一使命时会发生什么。

这些案例回答了一个问题：*“当全机构协同工作时，到底是什么样子的？”*

## 目录内容

### [nexus-spatial-discovery.md](./nexus-spatial-discovery.md)

**内容**：一次完整的产品探索练习。8 个智能体并行工作，评估一个软件机会并产出了一份统一的计划。

**场景**：通过 Web 研究，发现了一个处于“AI 智能体编排”与“空间计算”交汇处的机会。随后，整个机构被同时部署，产出了以下内容：

- 市场验证与竞品分析
- 技术架构（包含完整 SQL Schema 的 8 服务系统设计）
- 品牌策略与视觉识别系统
- 市场准入 (GTM) 与增长计划
- 客户支持运营蓝图
- 包含用户画像和旅程图的 UX 研究计划
- 包含 65 个 Sprint 任务的 35 周项目执行计划
- 空间界面架构规范

**使用的智能体**：
| 智能体 | 角色 |
|-------|------|
| 市场趋势研究员 | 市场验证、竞争态势分析 |
| 后端架构师 | 系统架构、数据模型、API 设计 |
| 品牌守护者 | 定位、视觉识别、命名 |
| 增长黑客 | GTM 策略、定价、发布计划 |
| 客户支持专员 | 支持层级、入职引导、社区 |
| 用户体验研究员 | 用户画像、旅程图、设计原则 |
| 项目协调专家 | 阶段计划、Sprint 规划、风险登记 |
| XR 界面架构师 | 空间 UI 规范 |

**核心启示**：所有 8 个智能体并行运行，产出了连贯且相互引用的计划，几乎没有沟通成本。该产出展示了机构在单次会话中实现从“发现机会”到“交付完整蓝图”的能力。

## 添加新案例

如果你运行了一次有趣的多智能体协作练习，请考虑将其添加到此处。优秀的案例应展现：

- 多个智能体围绕共同目标进行协作
- 机构能力的广度
- 智能体定义在现实场景中的适用性
